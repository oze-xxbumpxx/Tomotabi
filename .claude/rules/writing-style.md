# Tomotabi 文章の書き方

人が読む文章はすべてこの書き方にする。対象はユーザーへの報告、`logs/`、`docs/`、Issue、PR の説明、レビューのコメント、コードのコメント。
目的は、読んだ人がすぐ意味をつかめること。整って見えることではない。

## 書く前に

- 誰が読むかを決める。決まらないときは「この会話を見ていない、明日のユーザー」とする。
- 言いたいことを 1 文で言えるか確かめる。言えないなら、まだ書かない。

## 書き方

- 結論を最初の 1 文に書く。前置き・あいさつ・「まとめると」は書かない。
- 何が・いくつ・どれかを具体的に書く。「多くの」「様々な」「一部の」は、数か名前に置き換える。置き換えられないなら、その文を消す。
- 1 文に言いたいことは 1 つ。長くなったら切る。
- 見出しには中身を書く。読み手が見出しだけで結論がわかるようにする。
- 漢語より和語。「実施する」→「する」、「確認を行う」→「確かめる」、「〜することが可能」→「〜できる」。
- 専門用語は、読み手が知らなければ一度だけ言い換えを添える。
- 箇条書きは、並べるものが本当に並列なときだけ使う。理由と結論のつながりは文で書く。
- 書いたあと、消しても意味が変わらない言葉を全部消す。

## 使わない書き方

| 使わない                                          | 理由                                         | 直した例                                           |
| ------------------------------------------------- | -------------------------------------------- | -------------------------------------------------- |
| 160 本の検証で見えた限界と本質                    | 抽象名詞を並べて、中身を見出しに書いていない | 160 本で試した。敬語は直せたが、段落のクセは残った |
| 〜が見えてきた / 〜が浮き彫りになった             | 発見の演出。何がわかったかを書けばよい       | 〜とわかった                                       |
| 〜の本質は〜 / 〜という観点で                     | 言葉を大きくしているだけ                     | 何の話かを直接書く                                 |
| 〜することが可能です                              | 長い                                         | 〜できます                                         |
| 様々な観点から検討した結果、A とした              | 何と比べたかがない                           | A と B を比べて、〜なので A にした                 |
| 重要なのは〜という点です                          | 前置き                                       | 〜が大事です（または本題から書く）                 |
| 速く・安全で・使いやすい                          | 語呂のために 3 つ並べている                  | 本当にある利点だけを書く                           |
| 〜と言えるでしょう / 〜かもしれません（根拠なし） | ぼかし。言い切れないなら理由を書く           | 〜です / 〜は試していないのでわからない            |
| ——（ダッシュ）での言い換え・付け足し              | 翻訳調                                       | 文を切るか、括弧にする                             |
| 絵文字・太字の多用                                | 目立たせたいところがわからなくなる           | 太字は読み落とされると困るところだけ               |

## この表の育て方

ユーザーが「AI っぽい」「わかりにくい」と言った書き方は、この表に 1 行足す。
足すのは、実際に出てきた文と直した文のペアにする。一般論は足さない。
