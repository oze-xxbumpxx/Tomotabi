# Handoff: Tomotabi デザイン v3

## 概要
本人とパートナーの**二人だけ**が使う旅行アプリ。しおり（予定）・記録（支払い・達成・予約）・精算をまとめる。すべての旅行の参加者はこの二人で固定で、メンバーの招待・選択・人数の表示はない。
v3 は 2026/9/23 のデザインレビューを反映した版。見た目（色・書体・アイコン・タイムライン）は v2 のまま。業務ルールの詳細は「Tomotabi デザイン依頼書（Claude Design 用）」が正。

**決定事項（v2 から変更なし）**
| 項目 | 決定 |
|---|---|
| 書体 | 1b 丸ゴシック（端末標準のみ、Web フォントなし） |
| アプリアイコン | 2d 上から見た道路 × ピン |
| 画面内アイコン | Phosphor Icons（MIT） |
| ホーム画面 | 3b タイムライン |
| タブ構成 | ホーム / しおり / 記録 / 精算 ＋主操作「支払いを記録」 |

## デザインファイルについて
同梱の HTML は**デザインの参考資料**で、本番コードではない。実装先は **Next.js（React）の Web アプリ**。スタイルは CSS カスタムプロパティ（下のトークン名）で、アイコンは `@phosphor-icons/react` で作り直すこと。

- `Tomotabi 画面一式 v3.dc.html` … **実装の主な参照先**。各画面の上に「v3 修正」「v3 新規」の印、下に「v2 から：」の変更点を記載。
- `Tomotabi デザインシステム v2.dc.html` … 分析・書体・アイコン・ホーム 3 案。
- `Tomotabi デザインシステム 2a.dc.html` … v1。色トークン・基本部品・状態表示（読み込み・更新できていません・保存中）。**v2・v3 で上書きしていない部分は v1 の仕様に従う。**
- ブラウザで開くと表示できる（`support.js` を同じフォルダに置くこと）。
- 画面の PNG は v2 のものから作り直していない（必要なら書き出す）。

## v3 の変更点

### 最優先の修正（1〜5）
1. **二人専用**：記録一覧の「· 3 人」、旅行の切り替えの人数、予定詳細の「3 名」、精算の「そうた」の行、アイコン「メンバー（users-three）」を削除。

## サンプルデータ
負担額は「支払った人以外の負担を円未満切り捨て、残りを支払った人が負担」で計算。

| 支払い | 金額 | 払った人 | 分け方 | ひなた | あおい |
|---|---|---|---|---|---|
| 参道で朝ごはん | 2,400 | ひなた | 折半 | 1,200 | 1,200 |
| 八ツ橋 | 1,150 | ひなた | ひなたが全額 | 1,150 | 0 |
| 京都駅からタクシー | 2,850 | あおい | 折半 | 1,425 | 1,425 |
| 旅館の追加料金 | 7,600 | あおい | 割合（ひなた 60%・あおい 40%） | 4,560 | 3,040 |
| 湯豆腐の夕食 | 7,001 | ひなた | 折半 | 3,501 | 3,500 |
| 稲荷の茶屋（取り消し済み） | 900 | あおい | 折半 | 対象外 | 対象外 |

精算：**ひなた → あおい 1,285 円（対象 5 件）**。ひなたは支払った額 10,551 円・負担額 11,836 円、あおいは 10,450 円・9,165 円。合計 21,001 円＝二人の負担額の合計。

## 振る舞い
- ボタン・押せるカードは押している間 `scale(.97)`、0.15 秒。
- 保存成功：トースト「支払いを記録しました」を上部に 2 秒。
- 動きは 0.2〜0.4 秒で一度だけ。`prefers-reduced-motion` では最終形を表示。
- 「今」の位置と「あと ○ 時間 ○ 分」は 1 分ごとに更新。

## 必要なデータ
- 旅行：名前、開始日・終了日、状態（出発前 / 旅行中 / 終了）。参加者は二人で固定
- 予定：名前、種類（場所・食べ処・買い物・宿・移動）、日付、時刻（未定あり）、メモ、達成（誰が・いつ）、予約済み（誰が・いつ）、取りやめ
- 支払い：金額、払った人、分け方（折半 / 払った人が全額 / もう一人が全額 / 割合）、割合、確定した二人の負担額、用途、関連予定、登録者と時刻、取り消し
- 精算：向き・金額・対象件数、確認（作成日時・固定した対象と金額）、完了の記録

## 今回の範囲外
- 第 2 弾（M2 の前）：旅行の作成、予定の追加・編集、日の移動、予定の詳細の操作、取りやめの確認、予約の注意書き、長い旅行の日付。
- 第 3 弾（M4 の前）：記録一覧の絞り込み（予約を含む）、支払いの詳細、取り消し後の入れ直し、精算の確認画面の残りの状態、精算履歴、精算の取り消し、精算の完了後。
- 第 4 弾：通知設定、ダークモードの各画面。
