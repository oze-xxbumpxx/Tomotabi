画面内アイコン · Phosphor Icons を採用

Lucide には塗りの形がないため、同じ形で「線 / 塗り / 太線」を持つ Phosphor（MIT）を選びました。実装は phosphor-react-native または @phosphor-icons/react。

線 → 塗りタブは未選択が線、選択中が塗り
16px 以下は太線バッジ・小さなボタンは bold
大きさは 3 段16 バッジ / 20 行 / 24 タブ・ボタン
