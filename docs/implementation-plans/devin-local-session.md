# 実装計画: devin-local-session

- 前提となる設計書: docs/designs/devin-local-session.md（PR #270、2026-10-24 承認）
- 試験計画: docs/tests/devin-local-session.md
- 変更レベル: L2。ハーネスだけを変え、アプリのコードは触らない。
- 実装ルート: Orchestrator（メインの会話が直接書く）。判断理由: 設計を書いて確かめの起動をした会話の続きで、変える関数が絞れているため。

## 手順

| 順  | 対象                                              | すること                                                                                                                                                                                                                                                          | 完了条件                             |
| --- | ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| 1   | 確かめの起動                                      | 一時フォルダで手元のDevinを1回起動し、一覧と書き出しにIDが出るまでと、2つ目のセッションができないことを記録する                                                                                                                                                   | 設計書の「確かめの結果」に記録がある |
| 2   | `delegation-launch.mjs`                           | 専用クローンのロックと起動の前の一覧を、担当の確保（claim）より前に置く。`--export`の書き出し先を渡す。起動のあと60秒いっぱい一覧を読み、最後まで新しいIDがちょうど1つのときだけ確定する。書き出しが出ていれば照合する。クラウドは`cloud_launch_verified`で止める | 試験計画のLS-01〜LS-09が通る         |
| 3   | `delegation-shared.mjs`・`delegation-control.mjs` | `started`を、タスクの`runner`で分ける。手元はURLが空でIDだけ、クラウドは今どおり                                                                                                                                                                                  | LS-10・LS-11が通る                   |
| 4   | 設定                                              | `cloud_launch_verified: false`を足す                                                                                                                                                                                                                              | ハーネスの全試験が通る               |
| 5   | 手順書                                            | `review-devin-pr`と`docs/devin-setup.md`に、手元の起動の流れ・ロック・確かめの起動の例外を書く                                                                                                                                                                    | 書いてある                           |
| 6   | 設定のPR（別）                                    | ユーザーのマージ後、`cli_launch_verified`と`migration_complete`を`true`にする                                                                                                                                                                                     | ユーザーのマージ                     |

## 依存関係

1の結果（書き出しが作業の終わりまで出ない見込み）で、2の確定の方法を、設計の切り替え先（ロックと一覧の読み比べ）にした。6は2〜5のマージのあと。

## リスクと戻し方

- ロックが残ると、次の起動が止まる。動いている起動が無いことを確かめてから、人が消す。
- 戻すときは、このPRを戻す。起動を止める2つの設定は`false`のままなので、戻しても起動はしない。
