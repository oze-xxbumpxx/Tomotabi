## 依存関係

2のコマンドの形が決まってから、3（差し込み口）・4（status）・6（手順のコマンド）を書く。1は2より前に確かめたかったが、見本のページを作るのに2が要るため、2と3のあとで確かめた。

## リスクと戻し方

- ページのデータベースが使えなくなったら、コピーして貼る経路だけで続けられる（ひな形は保存できないときにコピーだけを出す）。
- 戻すときは、settings.jsonのフックの1行を外せば、ほかの手順は今までどおりチャットで問いを出す形に戻せる。記録のMarkdownは残る。
