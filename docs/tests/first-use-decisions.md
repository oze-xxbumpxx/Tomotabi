# 試験計画: first-use-decisions（初めて使った人のレビューの残りを直す）

- 設計書: `docs/designs/first-use-decisions.md`
- 実装計画: `docs/implementation-plans/first-use-decisions.md`
- レベル: L2

## 何を確かめるか

6つの直しはどれもブラウザの画面だけで、APIとDBは変えない。単体の試験では、画面に出る文字・リンクの行き先・付く見た目の印（クラス）を確かめる。幅と文字の大きさは単体の試験では見られないので、結合検証環境で目で見て確かめる。

冪等性と障害系は対象外にする。保存と取得の処理を変えないためで、今の試験がそのまま守る。

## 観点

試験のファイルは、今ある画面ごとの試験に足す（`apps/web/tests/`。vitestの`include`は`tests/**/*.test.tsx`）。

### 精算の「支払いを記録」（`wide-and-quiet`、`trip-tab-bar.test.tsx`・`settlement-screens.test.tsx`）

| 観点                       | 前提                             | 操作 | 期待                                                                            |
| -------------------------- | -------------------------------- | ---- | ------------------------------------------------------------------------------- |
| 精算では小さなボタン       | 精算の画面、オンライン           | 開く | 主ボタンが`main-action-quiet`を持ち、`/trips/{id}/payments/new`へのリンクのまま |
| ほかの画面は今のまま       | ホームの画面                     | 開く | 主ボタンが`main-action-quiet`を持たない                                         |
| オフラインでも同じ形       | 精算の画面、オフライン           | 開く | 押せない見た目（`aria-disabled`）に`main-action-quiet`が付く                    |
| 指定した主ボタンは変えない | 予定の詳細（`action`を渡す画面） | 開く | 主ボタンが`main-action-quiet`を持たない                                         |

### 履歴の取り消しの行（`cancel-row-and-notify-entry`、`records-screens.test.tsx`）

| 観点                           | 前提                               | 操作               | 期待                                                   |
| ------------------------------ | ---------------------------------- | ------------------ | ------------------------------------------------------ |
| 取り消しの行に金額が出ない     | 支払いと、その取り消しの記録がある | 履歴を開く         | 取り消しの行に金額が無く、「精算から外しました」が出る |
| 元の行は今のまま               | 同上                               | 履歴を開く         | 元の支払いの行に金額と「取り消し済み」が出る           |
| 行を押した先は今のまま         | 同上                               | 取り消しの行を押す | 支払いの詳細へ進む                                     |
| 達成・予約の取り消しは変えない | 達成の取り消しの記録がある         | 履歴を開く         | 「精算から外しました」が出ない                         |

### 通知の設定への入口（`cancel-row-and-notify-entry`、`trips-screen.test.tsx`）

| 観点                     | 前提                   | 操作             | 期待                                                            |
| ------------------------ | ---------------------- | ---------------- | --------------------------------------------------------------- |
| リンクがある             | 旅行が1件以上          | 旅行の一覧を開く | 「通知の設定」のリンクがあり、行き先が`/settings/notifications` |
| 旅行が無いときも出る     | 旅行が0件              | 旅行の一覧を開く | 「通知の設定」のリンクがある                                    |
| 取得に失敗したときも出る | 旅行の一覧の取得が失敗 | 開く             | 読み込み失敗の表示と、「通知の設定」のリンクが両方ある          |

### 相手の印（`partner-tag`、`home-screen.test.tsx`・`settlement-screens.test.tsx`・`payments-screens.test.tsx`）

| 観点                    | 前提                   | 操作         | 期待                                                   |
| ----------------------- | ---------------------- | ------------ | ------------------------------------------------------ |
| ホームの精算のカード    | 相手から自分へ渡す     | ホームを開く | 相手の名前に「（相手）」が付き、自分の名前には付かない |
| 精算の受け渡し          | 自分から相手へ渡す     | 精算を開く   | 相手の名前に「（相手）」が付き、自分の名前には付かない |
| 支払いの詳細            | 相手が払った支払い     | 開く         | 払った人と負担の内訳の相手の名前に「（相手）」が付く   |
| 名前が取れない          | 参加者の一覧が取れない | ホームを開く | 「相手（相手）」と出ない                               |
| 名前が1つの所は変えない | 相手の記録がある       | 履歴を開く   | 履歴の行の名前に「（相手）」が付かない                 |

## 回帰の範囲

- 下のタブと主ボタンは、ホーム・しおり・履歴・精算・予定の詳細・支払いの詳細の6つの画面で使う。今の試験（`trip-tab-bar.test.tsx`ほか）がそのまま通ることを確かめる。
- 補足の文字の大きさを変える規則は、精算・支払いの記録・履歴・ホーム・競合の表示で使う。見た目は結合検証環境で確かめる。
- E2E（`npm run test:e2e`）は、取り消しの行の文字か名前の文字を探している所があれば、新しい形に直して通す。

## 結合検証環境で見て確かめること

3つのタスクがマージされたら、結合検証環境に出し、パソコンの幅（1280px）とスマートフォンの幅（375px）で見る。

- 広い画面で、本文・下のタブ・主ボタン・下からの小さな画面の幅がそろって48remになっている。スマートフォンの幅では今の見た目のまま。
- 精算の画面の「支払いを記録」が枠線だけの小さなボタンで、「受け渡しの内容を確かめる」と見分けられる。
- 補足の文字が12pxで、明るい画面と暗い画面の両方で読める。詰めて並べた所（精算の小見出し）で崩れていない。
- 「（相手）」が名前の後ろに小さく出て、行が崩れていない。
