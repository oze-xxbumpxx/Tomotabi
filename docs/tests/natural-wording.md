# 試験計画: natural-wording（画面の言葉と表示を、使う人の言い方に直す）

- 設計書: `docs/designs/natural-wording.md`
- 実装計画: `docs/implementation-plans/natural-wording.md`
- レベル: L2

## 何を確かめるか

直しはブラウザの画面だけで、APIとDBは変えない。単体の試験では、画面に出る文字、表示の条件（印・主ボタン・残り時間・説明の文）、ボタンの見た目の印（クラス）、読み直しのボタンが読み込みを呼ぶことを確かめる。色と間隔は、各PRの画像と結合検証環境で目で見て確かめる。

送る本文の形は変えないので、冪等性と障害系の今の試験がそのまま守る。言葉を変えた所は、今の試験の期待を新しい言葉に直す。古い言葉が残っていないことは、各PRで`grep`して確かめる。

試験は今ある画面ごとの試験のファイル（`apps/web/tests/*.test.ts(x)`）に足す。ブラウザの試験は`e2e/tests/`。

## 1. 誤解する表示

| 観点                         | 前提                                                                    | 操作                                               | 期待                                                                                     |
| ---------------------------- | ----------------------------------------------------------------------- | -------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 期間に入った旅行の知らせ     | 開始していない旅行で、今日が開始日                                      | ホームを開く                                       | 見出し「旅行の日になりました」と、「旅行を開始する」を押すと印が変わる本文               |
| 開始日より前の印             | 開始していない旅行で、今日が開始日の前日                                | 印を出す                                           | 「出発前」                                                                               |
| 開始日の印                   | 開始していない旅行で、今日が開始日                                      | 印を出す                                           | 「開始待ち」                                                                             |
| 期間のあとの印               | 開始していない旅行で、今日が終了日の翌日                                | 印を出す                                           | 「開始待ち」                                                                             |
| 開始した旅行の印             | 開始した旅行                                                            | 印を出す                                           | 「旅行中」（今のまま）                                                                   |
| 達成のあとの主ボタン         | 達成のある場所の予定                                                    | 予定の詳細を開く                                   | 主ボタンが無い。予約のボタンが画面の中の白いボタンとして出る                             |
| 達成の前の主ボタン           | 達成の無い場所の予定                                                    | 予定の詳細を開く                                   | 主ボタンが達成のボタン（今のまま）                                                       |
| 残り時間を出さない           | 達成のある予定 / 取りやめた予定                                         | 予定の詳細を開く                                   | 残り時間が無い                                                                           |
| 残り時間を出す               | 達成の無い、これからの予定                                              | 予定の詳細を開く                                   | 残り時間が出る                                                                           |
| 旅行の一覧の見出し           | 旅行が2つ                                                               | 旅行の一覧を開く                                   | 見出し「旅行」。旅行のメニューの「旅行を切り替え」は今のまま                             |

| 開始の前に支払いを記録できる | ブラウザの試験。開始していない、期間中の旅行                            | 支払いを記録する                                   | 保存でき、履歴に出る                                                                     |

## 2. 記号と空白

| 観点             | 前提                         | 操作             | 期待                                                                              |
| ---------------- | ---------------------------- | ---------------- | --------------------------------------------------------------------------------- |
| 履歴の行         | 支払いが1件                  | 履歴を開く       | 「9:11　ひなたが支払い・折半」の形。「·」と名前の前後の空白が無い                 |
| 金額と件数       | 精算していない支払いが2件    | 精算を開く       | 「12,000円」「2件」の形                                                           |
| 残り時間         | これからの予定               | 予定の詳細を開く | 「3時間19分」の形                                                                 |
| 何日目           | 3日の旅行の2日目             | ホームを開く     | 「3日のうち2日目」。その下の「過ぎた日 … これから」の文が無い                     |
| 日付と時刻       | `formatDateTime`に日時を渡す | 形にする         | 「11/10(火) 9:11」                                                                |
| 通知の設定の日付 | 登録した端末がある           | 通知の設定を開く | 「11/10(火)」の形                                                                 |
| 残りの確かめ     | なし                         | `grep`           | `apps/web/src`（`generated/`を除く）に「·」と、名前・数字の前後の半角の空白が無い |

## 3. 精算の言葉

| 観点                 | 前提                                   | 操作                         | 期待                                                                                                 |
| -------------------- | -------------------------------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------- |
| 主ボタン             | 精算していない支払いがある             | 精算を開く                   | 「精算の金額を確かめる」。下に説明の文が無い                                                         |
| 0円の主ボタン        | 二人の負担が同じ                       | 精算を開く                   | 「精算の金額を確かめる」と「お金のやり取りはありません」                                             |
| 金額の画面           | 精算の金額を開く                       | 開く                         | 見出し「精算の金額」。「作成した時点の対象と金額で固定しています」が無い                             |
| あとから増えた支払い | 金額の画面を開いたあとに支払いが増える | 開く                         | 「次の精算に入ります。この画面の金額は変わりません。」が出る                                         |
| 最後の確かめ         | 金額の画面                             | 「精算したことを記録」を押す | 見出し「精算したことを記録しますか？」、本文に「このアプリは送金しません。」、閉じるボタンは「戻る」 |
| 精算の履歴           | 0円で精算した                          | 精算の履歴を見る             | 「0円で精算」                                                                                        |
| 途中の精算           | 途中のものがある                       | 精算を開く                   | 「途中の精算」                                                                                       |
| 支払いの一覧         | 精算していない支払いが2件              | 精算を開く                   | 「まだ精算していない支払い2件」。「明細」「対象」が無い                                              |
| 残りの確かめ         | なし                                   | `grep`                       | 画面の文字列に「受け渡し」「明細」が無い                                                             |

## 4. 予定と履歴の言葉

| 観点               | 前提                                                     | 操作                             | 期待                                                                                                       |
| ------------------ | -------------------------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 種類から言葉       | `achievement-word.ts`                                    | 場所・食べ処・買い物・不明を渡す | 「行った」「食べた」「買った」「済んだ」                                                                   |
| 達成のボタン       | 場所・食べ処・買い物の予定                               | 予定の詳細を開く                 | 「行った」「食べた」「買った」                                                                             |
| 達成の確かめ       | 食べ処の予定                                             | 「食べた」を押す                 | 見出し「食べたことを記録しますか？」、本文に予定の名前と「相手に通知が届きます。」、閉じるボタンは「戻る」 |
| 達成の印           | ひなたが「行った」を付けた場所の予定                     | しおり・ホーム・予定の詳細を開く | 「行った・ひなた」の形                                                                                     |
| 履歴の行           | 買い物の予定に達成がある                                 | 履歴を開く                       | 「ひなたが買った」                                                                                         |
| ホームの最近の履歴 | 日程欄に無い過去の買い物の予定に、今日「買った」を付けた | ホームを開く                     | 「ひなたが買った」（「済んだ」ではない）                                                                   |
| 予定が読めない履歴 | 予定の読み込みが終わっていない                           | 履歴を開く                       | 「済んだ」で出る                                                                                           |
| 絞り込み           | 履歴                                                     | 絞り込みを見る                   | 「済んだ予定」                                                                                             |
| 予約               | 予約を付けられる予定                                     | 予定の詳細を開いて押す           | ボタン「予約済みにする」、確かめの見出し「予約済みにしますか？」、印「予約済み」                           |
| 説明の文           | 予定の詳細 / ToDoの詳細 / ToDoの一覧                     | 開く                             | 「達成を記録: …」「予約を記録: …」「予定にする: …」、ToDoの見出しの下の文が無い                            |
| 通知の文           | 達成・取り消し・予約・取り消しの通知                     | 中身を作る                       | 「予定を済ませました」「済ませた記録を取り消しました」「予約済みにしました」「予約済みを取り消しました」   |
| 残りの確かめ       | なし                                                     | `grep`                           | 画面の文字列に「達成」「予約を記録」が無い                                                                 |

## 5. そのほかの言葉

| 観点             | 前提                              | 操作               | 期待                                                                 |
| ---------------- | --------------------------------- | ------------------ | -------------------------------------------------------------------- |
| やり直しのボタン | 読み込みに失敗した画面            | 開く               | ボタンは「もう一度読み込む」、文は「〜を読み込めませんでした」       |
| 再送のエラー     | 同じ支払いの再送が記録済み        | 保存する           | 「この支払いはもう記録されています。」                               |
| 競合のエラー     | 相手が先に変えた                  | 保存する           | 「相手が先に変更しました。」                                         |
| 自分と相手       | 相手が全額を払った支払い          | 支払いの入力を開く | 「あおいが全額」。「もう一人」「あなた」「（自分）」が無い           |
| ToDoの追加者     | 自分が追加したToDo                | ToDoの一覧を開く   | 「ひなたが追加」                                                     |
| ToDoの状態       | 未完了と完了のToDo                | 一覧を開く         | 「未完了」「完了」                                                   |
| 通知の設定       | 登録が切れた端末 / 止められた端末 | 通知の設定を開く   | 「通知の登録が切れています」「通知の登録が止まっています」、「無効」 |
| 閉じるボタン     | 取りやめ・終了・削除の確かめ      | 開く               | 閉じるボタンは「戻る」                                               |
| 端数の説明       | 割り切れる金額 / 割り切れない金額 | 支払いの入力       | 割り切れないときだけ端数の説明が出る                                 |
| 旅行の一覧の説明 | 旅行の一覧                        | 開く               | アプリの紹介と印の説明の文が無い                                     |
| 残りの確かめ     | なし                              | `grep`             | 画面の文字列に「再試行」「取得できませんでした」「やめる」が無い     |

## 6. ボタンの色とメニュー

| 観点                 | 前提                                                                                 | 操作                   | 期待                                                             |
| -------------------- | ------------------------------------------------------------------------------------ | ---------------------- | ---------------------------------------------------------------- |
| 確定のボタンは橙     | 予定の入力・旅行の編集・旅行をつくる・日の移動・ToDoの追加・精算の最後の確かめ・通知 | 開く                   | 確定のボタンが橙のクラス                                         |
| 橙は1つまで          | 上の各画面と確かめ                                                                   | 開く                   | 橙のクラスのボタンが1つだけ                                      |
| 移るだけのボタン     | 精算 / 旅行が無いときの画面                                                          | 開く                   | 「精算の金額を確かめる」「新しい旅行をつくる」は黒のまま         |
| 予定の詳細のメニュー | 予定の詳細                                                                           | 右上の「…」を押す      | 「編集」「別の日に移す」「取りやめにする」が並ぶ                 |
| メニューから操作     | 予定の詳細のメニュー                                                                 | 「別の日に移す」を押す | 日の移動のシートが開く（「取りやめにする」も同じく確かめが開く） |
| 画面の中のボタン     | 予定の詳細                                                                           | 開く                   | 画面の中は「支払いを記録」と予約のボタンだけ                     |
