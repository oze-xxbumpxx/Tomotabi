# 試験計画: records-and-home（記録と4画面の完成）

- 前提となる設計書: docs/designs/records-and-home.md
- 要件: docs/requirements/records-and-home.md（F-・E-の番号はここ）
- 対象: API（達成・予約・記録の一覧・ホーム）、DBの権限、web（記録・ホーム・支払いの詳細・予定の詳細・受け渡しの確認・共通の下のタブ・端末に残す仕組み）、E2E。

## 観点の番号

- RU: 単体（DBを使わない）
- RD: 実DBのAPIの試験（`apps/api/tests/db/`）
- RW: 画面の試験（Vitest・Testing Library。APIは模擬）
- RE: E2E（Playwright）
- RM: 手動確認
