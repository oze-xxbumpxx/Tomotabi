# 受け渡し後に支払いが取り消された場合の訂正案

作成日：2026-09-06
状態：2026-09-06方針合意済み。受け渡し済みの場合の例外を追加する。具体的な画面文言・保持方式は設計案。

## 問題

確認画面で3,000円と表示され、実際に3,000円を受け渡した後に、確認対象の支払いが取り消されることがある。最新の内訳だけへ置き換えると、実際に渡した3,000円を記録できなくなる。再確認を案内するだけでは訂正は完結しない。

## 合意した方針

- まだ受け渡していない場合は、最新の内訳を再確認する既存方針を維持する。
- 既に確認した金額を全額受け渡している場合は、変更を明示したうえで、元の確認対象・金額による完了記録を可能にする。
- その完了記録に含む取り消し済み支払いの寄与は、次回の精算への調整として扱う。取り消した支払い自体は復活させない。
- 完了記録と必要な調整の反映は、片方だけ成立しないよう整合性を守る。具体的な保存方法はCursorで設計する。
- 相手が既に同じ対象を精算済みなら、その既存記録を表示し二重登録しない。対象の重複を許す例外ではない。
- 確認後の新規支払いは次回へ回す既存方針を維持する。訂正のために入れ直した支払いも新規支払いとして次回に含める。

この例外は「元の確認金額を全額受け渡した」場合に限る。任意金額の送金入力・部分精算・確認金額とは異なる受け渡しの処理は追加しない。

## 具体例

他の支払い・調整はないものとする。

| 段階 | 状況 |
|---|---|
| 元の支払い | あなたが二人分6,000円を支払い、折半で記録 |
| 対象確認 | 相手からあなたへ3,000円と表示 |
| 実際の受け渡し | 相手があなたへ3,000円を渡す |
| 訂正 | 元の6,000円は入力誤りだったため取り消し、正しい4,000円の折半を新規登録 |
| 完了記録 | 実際に渡した元の3,000円について完了を記録 |
| 次回の内訳 | 元の支払い取り消しによる逆向きの調整3,000円と、新しい支払いによる相手の負担2,000円 |
| 次回の受け渡し | あなたから相手へ1,000円 |

結果として、相手の実際の負担は3,000円−1,000円＝2,000円となり、正しい4,000円の折半と一致する。アプリが自動で返金するわけではない。相手から受け取った3,000円をなかったことにせず、次回の受け渡しで差額を調整する。

取り消しだけで新しい支払いを登録しない場合は、次回はあなたから相手へ3,000円となる。

## 画面の分岐案

対象変更を検知したら「確認後に支払いが取り消されました」と表示する。元の確認金額と変更された明細を確認できるようにする。

- 「まだ受け渡していない」：最新の内訳を再確認する。元の確認は完了にしない。
- 「確認した3,000円を受け渡し済み」：元の金額で完了を記録し、取り消し分を次回へ反映する。操作前にこの結果を説明する。

ボタン内の金額と方向は実際の確認内容から表示し、受け渡し済みを初期選択しない。最新の精算額を無言で元の金額へ戻す操作にはしない。

## 同時操作と整合性

対象の取り消しが完了記録の直前に起きた場合も、完了記録直後に起きた場合も、最終的な完了履歴と調整額は同じになるようにする。対象支払いの確定負担額を使い、割合や端数を計算し直さない。

同じ対象の先行精算がある場合は本例外より重複防止を優先する。同一対象の精算・調整はそれぞれ一度だけ成立させる。元の対象の一部が先に精算された場合も、そのまま元の確認を完了できるとは扱わず、競合を表示する。重複する別々の受け渡しが実際に発生した場合の訂正は、本案の対象外として別途判断する。

## この案を成立させる前提

- 元の確認対象・金額・各支払いの確定負担額を、外部送金サービスへ移動して戻った後も参照できる必要がある。
- 確認内容の期限切れや画面の再読み込みで、受け渡し済みの金額を記録できなくしない。保持・再開方式は詳細設計で定める。
- 精算自体の取り消しは、実際には受け渡していなかった等の完了記録の誤りに用いる。今回のように受け渡し自体は正しく行われた場合は、支払い訂正のためだけに精算を取り消さない。
- 完了記録を後から取り消す場合、元の支払いが既に取り消されていれば支払いを復活させず、当該完了に対する未精算の調整も残さないよう再計算する必要がある。既に後続の精算がある場合は、最新の有効な精算のみ取り消せる制限に従う。

## 合意に伴う変更

「対象の支払いが取り消された場合は完了記録を止めて再確認」を、受け渡し前の基本動作として維持する。受け渡し済みには本例外を追加し、合意事項・画面遷移・精算の受け入れ条件へ反映する。合意事項・基本設計案・画面遷移に反映済み。
