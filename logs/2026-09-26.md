## 気づき・メモ

- Better Auth の内部ロガーは DB エラー時に例外オブジェクトごと出力し、query params にセッション token が流れる。`logger.log` で message だけを pino に渡す形にして塞いだ（#37 のログ条件に触れる所見）。
- Testcontainers の `container.stop()` は既定でコンテナを削除する。再起動検証には `stop({ remove: false })` が必要。さらに Docker は stop/start で ephemeral ホストポートを振り直すため、復帰検証では pool の接続先を新ポートへ向け直す必要がある。
- pg Pool は `error` listener 無しだとアイドル接続の非同期エラーでプロセスが落ちる。`getPool()` に noop listener を追加した。
- 並行 PR が同じ日次ログに追記すると毎回衝突する。並行作業では、ログは最後にマージする PR か Claude Code がまとめて書く運用を検討する。
- express は `app.use("/api/auth", mw)` の中で `req.url` を相対パスに書き換える。mount 先の middleware が応答を終えると pino-http の finish 時点でも相対のままなので、ログの path は `req.originalUrl` を優先する（#43）。
- Docker Hub が 429 で `postgres:16-alpine` を取れないときは `mirror.gcr.io/library/postgres:16-alpine` を pull して `postgres:16-alpine` に tag すると test:api-db が動く。
- ローカルで Testcontainers を動かすとき、サンドボックス内では Docker の認証ヘルパーでイメージ取得が止まる。空の `DOCKER_CONFIG` を指定しサンドボックス外で実行すると動く。
- UT のカバレッジは 100% を目標にしない（ユーザー合意）。試験計画の観点を全部テストにし、認証・ドメインだけ分岐網羅を高く保つ。計測は M1-b4 の後に Devin へ依頼する。
